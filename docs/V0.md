# V0 experiment evidence

Local sandbox, CPU, PyTorch 2.10.0, Python 3.13. Seed 17; batch 64; two Torch threads; 512 evaluation examples sampled with a separate seed. The combinations are not guaranteed disjoint from training; this is not a strict generalization benchmark. Single run per configuration, no statistical confidence. All five unit tests passed. No benchmark on the owner's computer.

Random IoU .120760, untrained greedy IoU .058233. Model 86,820 parameters. Hybrid measured ~49,712 supervised actions/s and ~48,851 RL actions/s, including training but not setup or evaluation. These are tiny binary tasks, not complex brush or mesh operations.

RL-only can collapse to early stopping; reinforcement does not guarantee improvement. The full imitation run saturates the task before reinforcement. Compare against supervised-only with matched compute and strict held-out combinations before making claims of superiority.

Commands: python workers.py --supervised 20 --rl 500 --out runs/hybrid; python workers.py --supervised 500 --rl 200 --out runs/v0; python workers.py --supervised 0 --rl 500 --out runs/rl_only.
